# My Viral Post

Write a new LinkedIn post for **[PERSON NAME]** that matches their proven, best-performing style. This skill is built from that person's own content report and SOP, so it reflects what actually works for them — not generic LinkedIn advice from the internet.

> Replace `[PERSON NAME]` throughout and paste the key findings from the content report and SOP into the "Winning recipe" section below. The richer that section, the better the output.

## Core method

You can't write a post for someone without input from them. So the moment this skill is invoked, use the question tool to gather the right input before generating anything — tailored to what this person does best (their winning formats, angles, and topics from the recipe below). Get the raw material first, then generate.

After you have the input:

1. Generate several distinct angles/hooks (default 5, more on request), each grounded in the winning patterns.
2. Let the user pick their favorite(s).
3. Assemble the full post with them: the chosen angle, the complete caption written in their voice and cadence, and clear direction on the media (image/carousel) that should go with it — what it should contain and look like.
4. End with concrete next steps to make it even better.

## What to ask for (via the question tool)

Tailor the questions to the person, but cover: the topic or news they want to react to, the specific story/data/example they can bring (the human input the model can't invent), the goal of the post (reach, leads, authority), and any constraint (length, format preference).

Ask before generating. Never produce a generic post from a cold start.

## Voice rules

Match the person's voice exactly, as captured above. Default to: short sentences, varied length; "I" and "you"; active voice; concrete over clever. Avoid em dashes, emojis, and hype words (supercharge, unlock, game-changer, seamless, effortless, leverage, powerful) unless the person's own style clearly uses them.

## Honest guardrail

Don't repeat one ultra-viral recipe over and over — novelty fades and audiences tire of the same move. Mirror the winning patterns, vary the execution, and flag when a draft is leaning too hard on a formula they've already used recently.
