# Social Carousel Layout Templates

A reusable template set for branded social carousels. Six fixed slide templates that read as one cohesive visual sequence.

## Brand Rules & Constraints

1. **Palette:** Warm neutral background surfaces (`#EDE6DE`, `#F7F6F2`). A single accent hue used sparingly for emphasis words or key stat borders. Body text in dark charcoal (`#2B2624`), never pure `#000`.
2. **Typography:** Display serif for slide headlines, monospaced font for slide number tags, quiet readable sans-serif for body copy.
3. **Pacing:** 1 idea per slide. Max 30 words per slide canvas.
4. **Dimensions:** 1080 x 1350 px (4:5 aspect ratio).

## Slide Layout Blueprints

- **01 - Cover Slide:** Title headline (max 6 words), subtitle, primary visual container, and bottom-right swipe trigger ("Swipe ->").
- **02 - Context Slide:** Problem statement, high-contrast stat callout or code block.
- **03 to 05 - Framework Step Slides:** 1 step per slide, bold header, short body copy, clear visual illustration.
- **06 - CTA Slide:** Summary visual takeaway + clear comment/save prompt.
