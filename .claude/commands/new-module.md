Guides the creation of a new feature module under `modules/`.

Steps to perform:

1. Identify module category and objective.
2. Create directory under `modules/<category>/<module-name>/`.
3. Create router `SKILL.md` following the 9-dimension intent model.
4. Structure stage subdirectories and reference material.
5. Verify writing rules (`shared/writing-rules.md`) and run `node scripts/audit-compliance.js`.
