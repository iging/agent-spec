# Brand Presets for AI Agents

This directory contains 74 examples of what a highly effective `DESIGN.md` looks like. Each preset is based on the visual language of a well-known brand.

These presets are excellent resources for instructing AI coding agents on how to build user interfaces. An agent reading one of these presets will automatically adopt the typography, colors, shadows, border radii, and visual hierarchies defined within.

## How to use a Preset

If you want your project to adopt the visual identity of one of these brands:

1. Browse the folders in this directory to find a brand style you like.
2. Copy the `DESIGN.md` file from that brand's folder into the `context/` folder or the root of your own project.
3. Your AI agent will now use that `DESIGN.md` as its source of truth for all frontend engineering tasks.

_(Note: These files are provided as educational examples of how to write effective design documentation for AI agents. They are analytical interpretations of public design systems and do not contain proprietary source code.)_

## Building from Scratch

If you prefer to build a completely custom design system rather than using a preset, you can use the empty template located at `context/DESIGN.md` in the `agent-spec` root. It contains `[PLACEHOLDER]` markers to help you define your own colors, typography, and rules.
